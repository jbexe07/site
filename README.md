# Coelho News 🐰📰

Portal de notícias fictício, criado para praticar HTML e CSS. O site tem uma notícia em destaque e uma seção "Mais Notícias" dividida em Esportes, Economia e Tecnologia.

<!-- Link para ver o site funcionando. Troque se o endereço final for outro -->
🔗 **Demonstração:** [sitecueio.vercel.app](https://sitecueio.vercel.app)

## 📄 Páginas

| Arquivo | Descrição |
|---|---|
| `index.html` | Página inicial, com cabeçalho, menu, destaque do dia e Mais Notícias |
| `lernoticia.html` | Página de leitura da notícia em destaque |

## ▶️ Como rodar localmente

1. Clone o repositório:
```bash
   git clone https://github.com/jbexe07/site.git
```
2. Entre na pasta:
```bash
   cd site
```
3. Abra o arquivo `index.html` no navegador (clique duas vezes ou use a extensão Live Server do VS Code).

Não precisa instalar nada.
